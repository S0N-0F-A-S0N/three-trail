## 2024-11-11 - [Inline Vector Operations in WebGL/ThreeJS Render Loops]
**Learning:** In tight geometry generation loops (`setBrush` and particle emissions), intermediate `Vector3` allocations and function calls like `applyMatrix4` or `lerpVectors` create noticeable overhead. Extracting elements and doing manual math directly into typed arrays (`Float32Array`) yields significant performance improvements (up to ~38% for matrix expansion, ~10% for lerp inlining).
**Action:** When working on WebGL/ThreeJS applications, look for tight `for`-loops that populate geometry buffers. Avoid using intermediate `Vector3` or function calls (like `copy`, `applyMatrix4`, `lerpVectors`). Instead, perform mathematical expansions inline with primitive `number` operations to avoid object allocation and call overhead.
